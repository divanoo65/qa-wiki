# 编排 (Orchestration)

### 概念定义
在 Harness Agent 架构中，编排是指由核心大脑（Hermes LLM）根据任务目标，对一系列原子化工作流节点（Skill）进行动态调度与逻辑控制的过程。编排的核心在于将复杂的业务逻辑拆解为可执行的原子单元，并由大脑负责决定这些单元的执行顺序、依赖关系以及条件分支。与传统的硬编码流程不同，编排强调的是“决策与执行的分离”：编排逻辑存在于 Skill 外部，确保了大脑能够灵活地根据上下文环境，通过顺序执行或构建有向无环图（DAG）来完成复杂任务，而无需干预 Skill 内部的固定逻辑。这种机制使得系统具备了极高的灵活性与可扩展性。

### 技术细节
- **决策层级**：编排逻辑完全由 Hermes Brain 掌控，Skill 仅作为被调用的执行单元，不包含任何条件分支或业务决策逻辑。
- **执行模式**：支持线性顺序执行（Sequence）以及基于依赖关系的 DAG 执行模式。
- **解耦机制**：通过虚拟化接口，编排层无需感知底层执行环境（如本地环境或云端沙盒），实现了 Brain 与 Hands 的彻底解耦。
- **原子性**：编排的对象是封装了固定逻辑、具有明确输入输出的原子 Skill，这保证了编排过程的稳定性和可预测性。

### 应用场景
- **复杂任务自动化**：当一个业务目标需要跨越多个系统或环境（如代码部署、环境配置、监控检查）时，通过编排将这些步骤串联。
- **动态流程调整**：在执行过程中，根据前序 Skill 的输出结果，由 Brain 实时决定下一步调用哪个 Skill，实现自适应的工作流。
- **系统集成**：作为不同功能模块之间的粘合剂，将分散的原子功能（Skill）组合成符合特定业务需求的 SOP。
